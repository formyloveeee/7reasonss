SEVEN LITTLE REASONS — Anniversary Website

FILES
- index.html : page structure
- style.css  : design, responsive layout, paper effects and animations
- script.js  : seven editable reasons and interactions

RUN IN SPCK
1. Create a new project in SPCK.
2. Add these three files with the exact names above.
3. Copy each file's content into its matching file.
4. Save and tap Preview/Run. Keep all three files in the same project folder.
5. Internet is needed for Google Fonts; without it, fallback fonts still work.

PERSONALIZE
Open script.js and edit the seven objects inside `const reasons = [...]`.
Change `kicker`, `title`, `symbol`, and `copy`.
In index.html, edit the cover/sign-off and final letter to add your own memories.
The music button currently plays a very soft generated tone when tapped; it does not use a copyrighted song.

HOSTING
Upload all three files to the same GitHub Pages folder/repository. Do not rename style.css or script.js unless you also update the links in index.html.
